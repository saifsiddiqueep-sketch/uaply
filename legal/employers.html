Receiving applications from UAply

Last updated October 17, 2026.

UAply sends an application to an employer only after the employer has agreed in writing and set up one way to receive it. Until then, a person who swipes right on your job finishes on your own careers page, and UAply sends you nothing.

The ways to receive applications

You useWhat you createWhere
GreenhouseA Job Board API keyConfigure, Dev Center, API Credential Management
LeverA Postings API key (a Super Admin makes it)Settings, Integrations and API, API Credentials
AshbyAn API key with Candidates write and Jobs readAdmin, Integrations, API Keys
SmartRecruitersAn Application API keySettings, Admin, Credential Manager
WorkableAn API access token with the r_jobs and w_candidates scopes (an Admin makes it)Profile icon, Settings, Integrations, Apps, API Access Tokens
Anything elseA recruiting email address, or an HTTPS webhook address and a secretNothing to create in your system

The same for every way

  • Each application is one person who chose to apply, reviewed what would be sent, and agreed.
  • UAply never sends gender, race or ethnicity, veteran status or disability status.
  • If your form asks something the person's profile cannot answer, nothing is sent until the person answers it.
  • Your key stays on UAply's server. It is never shown, logged or used in test mode, and only submits applications to your published jobs.
  • You can stop at any time by revoking the key in your own system, and by telling us.
  • You make every hiring decision.

Getting set up

Email uaplytechnologies@uaply.net. We send the step-by-step page for your system (what is sent, the exact menu path, what the key can do, how to revoke it, what you see for each application) and the consent letter to sign or reply to. Nothing is sent to you before we have it.
