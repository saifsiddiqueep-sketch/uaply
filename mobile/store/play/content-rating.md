# Content rating questionnaire (Play Console > Policy > App content > Content rating)

The IARC questionnaire, answered for the UAply app. Email address for the rating certificate: the developer account email.

| Question | Answer | Why |
|---|---|---|
| Category | **All Other App Types** (utility, productivity, communication, or other) | A job search and application tool; not a game, not social media, not a store |
| Violence (any depiction) | No | |
| Sexuality, nudity | No | |
| Profanity or crude humor | No | |
| Controlled substances (drugs, alcohol, tobacco) | No | Job listings are employers' own text; UAply does not promote these |
| Gambling or simulated gambling | No | |
| Fear, horror | No | |
| Does the app allow users to interact or exchange content with other users? | **No** | Applications go to employers' hiring systems or the employer's own site; there are no profiles, posts, chat or messages between users in the release build. Help messages go only to the UAply team |
| Does the app share the user's current physical location with other users? | **No** | Device location stays on the device |
| Does the app allow users to purchase digital goods? | **No** | Free during early access; no buy buttons in the app |
| Does the app contain NFTs or blockchain content? | No | |
| Is the app a web browser or search engine? | **No** | It opens uaply.net; links to an employer's posting open that one page |
| Is it primarily a news or educational product? | No | |

Expected result: **Everyone** (ESRB), **PEGI 3**, IARC 3+. Being rated for everyone does not change who the app is for: the
**Target audience** screen (see `app-content.md`) sets **18 and over only**, as the Terms require.
