# Throwaway ("temporary", "10-minute") email domains that cannot be used to make a UAply account.
#
# Why: an application, its receipt and the employer's reply go to this address, so it must be one the person keeps. A sign-up with one of
# these domains (or a domain under one, like x.mailinator.com) is refused with: "Please use an email address you'll keep — temporary
# addresses can't be used for job applications." Read by auth_api.disposable_domains(); edits apply without a restart.
#
# How to edit: one domain per line, lower case, no "@". "#" starts a comment. Repeats are harmless (they are removed when read).
# Never add a domain real people keep for years (gmail.com, yahoo.com, outlook.com, a school's or employer's domain): only services whose
# whole point is a mailbox that disappears. Forwarding alias services (SimpleLogin, Firefox Relay, DuckDuckGo, iCloud Hide My Email,
# 33mail, Burner Mail) are left out on purpose: the mail reaches the person's real inbox.
#
# Source: every domain below was checked, on October 17, 2026, to be in the community list
#   https://github.com/disposable-email-domains/disposable-email-domains  (file disposable_email_blocklist.conf, CC0-1.0; the list PyPI
#   uses to refuse throwaway addresses; each entry there needs evidence that the service hands out throwaway inboxes). Only that
#   conservative list is used, never the 100,000-entry auto-generated ones (they flag privacy relays and obscure real domains).
#   The community list has about 4,000 entries; these are the best-known services. To use all of it, paste its lines below.
# Privacy relays (tools/data/relay-domains.txt) are checked first and always pass, even if a relay domain is ever added here.
